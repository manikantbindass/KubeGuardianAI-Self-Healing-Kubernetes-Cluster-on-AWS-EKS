# v1.0.0 release preparation

Status: **blocked / unpublished**, 2026-11-03. Application package versions remain 0.1.0. No v1.0.0 tag, GitHub release, merge, AWS apply or production promotion is performed by Phase 11.

## Prepared release notes

KubeSentinel AI connects Kubernetes evidence, incident analysis and policy-governed recovery. The release scope includes the Next.js operations workspace, typed FastAPI services, PostgreSQL migrations/queue records, Redis coordination, kind/Helm deployment, observability ingestion, advisory rules/statistical/Isolation Forest detectors, a scoped Go recovery operator, read-only incident intelligence and reviewed delivery/GitOps source.

Portfolio additions include the root editable 25-slide PowerPoint, technical report, slide PDF export, real application captures, evidence-derived charts, source manifests and reproducible authoring scripts. Original Apache 2.0 license and repository ancestry are preserved.

## Evidence boundaries

- ML evaluation: 177 synthetic held-out windows and two fault incidents; no real-cluster accuracy estimate.
- Recovery: selected isolated kind paths with durable action records; no repeated native-versus-Sentinel improvement claim.
- Performance: 900 Windows loopback health requests; PostgreSQL, queue and cluster saturation are not measured.
- Correlation: eight synthetic cases; fixture correctness does not establish production root-cause accuracy.
- AWS: infrastructure source validation only. No deployed endpoint, bill, live plan or cost saving is claimed.
- Live identity-provider certification, backup restoration, HA monitoring and real staging promotion remain unverified.
