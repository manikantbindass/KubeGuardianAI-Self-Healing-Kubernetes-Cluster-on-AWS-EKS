# Code of conduct

Be respectful, specific, and constructive. Welcome different backgrounds and levels of experience. Critique ideas and code, not people. Respect privacy and credit contributions.

Harassment, discriminatory language, threats, unwanted sexual attention, doxxing, and deliberate disruption are unacceptable in issues, reviews, discussions, and other project spaces.

Report concerns privately to the repository owner through a contact channel they publish on their GitHub profile. If none is available, request one without sensitive public details. A dedicated conduct contact and response SLA are maintainer follow-ups.

Maintainers should review reports confidentially, consider affected people's safety, document decisions privately, and respond proportionately: a correction request, warning, temporary restriction, or removal. Participants may request reconsideration privately. Maintainers follow the same standards.
